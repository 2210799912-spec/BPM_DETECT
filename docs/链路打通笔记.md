# PYNQ-Z2 音频 BPM 系统 · 链路打通笔记

> 用途：记录本工程所有"已实测验证、能打通链路"的方法与坑点，避免重复踩坑。
> 平台：PYNQ-Z2 (Zynq 7020, xc7z020clg400-1) | Vivid 虚拟机 | PL 单时钟域 100MHz
> 数据流：`ADAU1761 → adau1761 IP → axis_data_fifo → segment → bpm_detect → axi_dma → DDR`

---

## 1. 物理信号路径（收音方式）

- 输入：**耳机线麦克风(mic) 咪头**对准手机外放鼓点/节拍器，耳机插头插入**板载 MIC 座(U41)**。
- 座内 MIC1/MIC2 直连 ADDAU1761 的 MIC1(脚10)/MIC2(脚13)；MICBIAS 经 R503/R504(2.2k) 供电。
- 只走 MIC 这一路，**不经过 LINE-IN、不经过板载麦**。
- 参考正确配置：本工程 `test_io_probe_gain.py` / `test_music_gain.py` / `test_full_function.py`。

## 2. 时钟链（Codec 是 I2S 从，FPGA 是主）

```
PS FCLK0=100MHz → clk_wiz_0 → MCLK(25MHz) → ADAU1761 MCLK
                            → FPGA adau1761 IP 分频产生 I2S 主时序
                               BCLK≈3.125MHz / LRCLK≈48.8kHz
```

- 25MHz = **512 × 48.8kHz**，严格自洽。**不要改 clk_wiz 的 MCLK**。
- Codec 用 **MCLK 直通（不用 PLL）**：PLL 输出 = 1024×48.8k ≈ 49.99MHz **超上限**(45.158–49.152MHz)。

### ADAU1761 关键寄存器（I2C 地址 0x3B，16 位寄存器地址）
| 寄存器 | 值 | 含义 |
|--------|-----|------|
| R0 (0x4000) | 0x03 | INFREQ=512×fs + **COREN=1 核心时钟使能**(默认0=关) + CLKSRC=直通 |
| R1 (0x4002) | (PLL 6字节) | **本工程不用 PLL**，保持默认 |
| R65 (0x40F9) | 0x7F | 时钟使能 0：SLEW/ALC/DEC/SOUT/INT/SIN/SP 全使能(默认全0=掉电!) |
| R66 (0x40FA) | 0x01 | 时钟使能 1 |
| R17 (0x4017) | 0x00 | Converter 控制 |
| R29/30 (0x4015/16) | 0x00 | Serial Port 控制(从 I2S) |

**核心坑**：Codec 无自动初始化；R0 COREN 默认 0、R65 默认全掉电 → 不加时钟配置则左声道恒满幅/无信号。

## 3. MIC/Codec 增益配置（已实测生效）

顺序：先时钟使能 → 再增益 → 再模拟验证。

```python
cfg = [

    (0x4000, 0x00, "R0 先复位"),   # 视情况
    (0x4000, 0x03, "R0 时钟使能+512xfs 直通"),
    (0x40F9, 0x7F, "R65 时钟使能0 全开"),
    (0x40FA, 0x01, "R66 时钟使能1"),
    # MIC 增益
    (0x400A, 0x11, "R4 左混频使能"),
    (0x400B, 0x10, "R5 左 MIC +20dB boost"),
    (0x400C, 0x11, "R6 右混频使能"),
    (0x400D, 0x10, "R7 右 MIC +20dB boost"),
    (0x400E, 0x7F, "R8 左输入音量(0x60 中档防削波 -> 0x7F 更大)"),
```

## 4. I2C 读写（smbus2）——关键坑

- **地址**：Codec 7 位地址 `0x3B`（I2C 扫描确认）。
- **写**：`bus.write_i2c_block_data(CAD, (reg>>8)&0xFF, [reg&0xFF, val])`
- **读（必须用 i2c_rdwr 保持 restart）**：
  ```python
  msg = i2c_msg.read(CAD, 1)
  bus.i2c_rdwr(i2c_msg.write(CAD, [reg>>8, reg&0xFF]), msg)
  val = int(msg[0])
  ```
- **大坑**：`write_byte_data + read_byte` 会丢 restart，恒返回 0x0F（假 FAIL），**不要用**。
- `i2c_rdwr` 返回 None，数据在 msg 对象里；`msg[0]` 是 bytes，需 `int(...)` 转。

## 5. Codec 寄存器跨重载保留

- ADAU1761 寄存器在 **overlay 重载 / Jupyter 内核重启后仍保留**（只有整板断电才复位）。
- 之前乱写的值(0x4009=0x1F, 0x400B=0x18, 0x400E=0xFF 等)必须**整板断电**清除，重启 overlay 无效。
- 测试前若异常，优先怀疑残留寄存器状态。

## 6. 数字链路（segment / DMA / 采样解包）

### segment_stream_0 (0x43C0_0000) 字数闸门
- 写 `seg.mmio.write(0x00, N)` 放行 N 个样本后停住；**需重写 0x00 才继续**。
- 常见错：不写 N 就收流 → 数据停住，env 读 0x0（不是检测器坏，是流没放行）。

### AXI DMA (0x41E0_0000)
- 分配缓冲：`buf = allocate(shape=(N,), dtype=np.uint32)`
- 传前 `buf.flush()`，传后 `buf.invalidate()`。
- `transfer` → `start` → 轮询 `dma.recvchannel.idle` 或 `wait()` 再读。
- 状态：`dma.mmio.read(0x04)`，idle=(bit1==1)。**不要 cache 不一致时直接读**。

### 24-bit 采样解包（右对齐有符号）
```python
# uint32 数组
s = (a ^ 0x800000).astype(np.int32) - 0x800000
# 单值 mmio
dec = ((raw ^ 0x800000) & 0xFFFFFF) - 0x800000
```

### 双声道
`buf[::2]` 左声道、(本工程用左声道)；右声道默认静音(左声恒定满幅/右声静音 = 时钟失锁/配置未生效特征)。

## 7. BPM 检测 IP（bpm_detect，HLS）

- **寄存器基址 0x10**（头文件注释的 0x40 是旧版错误，勿信）；偏移见下。
- 接口：`ap_ctrl_none` 流式、无中断端口、audio_in→audio_out 透传。

| 偏移 | 寄存器 | 内容 |
|------|--------|------|
| 0x10 | regs[0] | total_samples（C-sim 有界退出开关，硬件忽略） |
| 0x28 | regs[6] | **BPM** (IEEE754 float) |
| 0x2C | regs[7] | **峰数 / debug_cnt** |
| 0x30 | regs[8] | 包络 env_sum 低32位 |

### 算法参数（关键；阈值自锁已修）
| 常量 | 旧(自锁) | 新(修好) | 说明 |
|------|---------|---------|------|
| BASE_SHIFT | 12 | **17** | IIR 基线时间常数；17≈2.17s 只跟音乐底噪 |
| ADAPT_FACTOR | 6 | **3** | thr=base×ADAPT |
| REFRACTORY | 15104 | 15104 | ≈0.25s 不应期，封顶~240BPM |
| ENV_SHIFT | 10 | 10 | 能量窗 1024≈17ms |
| (FS_HZ=60418, BPM_CONST=3625080) | | | |

> **阈值自锁根因**：`BASE_SHIFT=12`(快) 时 base 追平鼓点能量 → `thr=6×base` 恒大于 env_sum → 永不触发，BPM 恒 0，与输入幅度无关。改 `BASE_SHIFT=17 + ADAPT=3` 后 base 只反映音乐底噪，鼓点瞬态超 3 倍底噪即触发。已用 py_mirror + 实测信号形态验证（旧 0 峰 → 新正常触发）。
> **C-sim 判据**：TB 就是自锁回归测试——参数再退化则峰数=0 判 FAIL。

### 修改后流程（先改 IP 再动 BD）
1. 改 `bpm_detect.h`（BASE_SHIFT / ADAPT）
2. `csim` → 期望 `TEST PASS`(BPM≈120, debug_cnt≥4)
3. `csynth` → 查 Fmax（旧 137MHz，只改常量不破坏）
4. 打包 `bpm_detect.zip`（ap_ctrl_none、无中断，维持不变）
5. Vivado 换 IP → 综合实现 → 新 bit
6. 上板跑 test_full_function（先全断电清 codec 寄存器）→ 打鼓点读 0x28 出非零 BPM

## 8. 完整链路验证脚本（test_full_function.py 流程）

四段式，见本目录 `test_full_function.py` / `.ipynb`：
1. **时钟初始化**：R0/R65/R66 ＋ 增益 cfg
2. **增益写读校**：全寄存器写后读回 `int(msg[0])` 校验
3. **模拟路径验证**：`adau.mmio.read(0x00)` 左声道，看幅度是否为真实 AC（非恒满幅）
4. **DMA/BPM**：段闸放行 → DMA 收流 → 读 0x28/0x2C/0x30

打通判据：Codec 幅度≠恒满幅 且 BPM>0 且 峰数≥4。
