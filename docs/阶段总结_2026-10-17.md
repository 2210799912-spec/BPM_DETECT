## 二、全链路怎么跑（信号路径）

```
手机外放(鼓点/带鼓点歌曲) → MIC(耳机线拾音)
   ↓ I2S 4线(MCLK 25MHz / BCLK / LRCLK / SDATA)
ADAU1761 (codec, I2C 0x3B 配置) → adau1761_0.M_AXIS (32bit AXIS)
   ↓
axis_data_fifo_0 (弹性缓冲, 吸收抖动)
   ↓
segment_stream_0 (S_AXIS→M_AXIS 透传 + 寄存器计数门控 REG0=8192)
   ↓
bpm_detect_0.audio_in
   │  内部 DATAFLOW 4 进程:
   │    unpack_axi → pan-tompkins: sample_process(差分→平方→包络→自适应阈值→不应期)
   │             → bpm_process(峰-峰间隔→BPM历史平均) → writeback(写0x28/0x2C/0x30)
   ↓
bpm_detect_0.audio_out (原始音频原封透传)
   ↓
axi_dma_0.S_AXIS_S2MM → axi_mem_intercon → PS.S_AXI_HP0 → DDR(0x0)
```

**双口并行**：音频数据一路经 DMA 进 DDR 供显示；BPM 结果一路经 s_axilite 寄存器 0x28 被 PS 轮询读。两条路同时走，天然满足"波形图和 BPM 波形图同时生成"。

## 三、BD 构造（依据 XSA34/design_1.tcl）

**IP 清单与关键配置：**

| IP | VLNV/配置要点 | 作用 |
|----|--------------|------|
| processing_system7_0 | PS，ARM Cortex-A9×2 666MHz，FCLK_CLK0=**100MHz**，EMIO I2C0，USE_DMA0，USE_S_AXI_HP0 | 系统核心 |
| axi_dma_0 | `c_include_mm2s=0, c_include_s2mm=1, c_include_sg=0` | 仅收流到DDR |
| axi_interconnect_0 | `NUM_MI=4` | PS GPIO→4个外设寄存器口 |
| adau1761_0 | 用户IP，I2S **Master**，32bit AXIS，`s_axis_tvalid`由常量拉高 | codec接口 |
| proc_sys_reset_0 | — | 复位分配 |
| xlconcat_0 | `NUM_PORTS=1`，In0=dma s2mm_introut → IRQ_F2P | **新IP无中断端口，已减为1路** |
| axi_mem_intercon | `NUM_MI=1` | DMA→HP0 DDR |
| segment_stream_0 | 用户IP，透传+计数门控 | 帧控制 |
| bpm_detect_0 | `xilinx.com:hls:bpm_detect:1.0`（本次替换为 Pan-Tompkins 新版） | BPM检测 |
| clk_wiz_0 | 100→**25MHz** MCLK（MMCM 9.125/36.5），`resetn`高有效接常量 | 给codec主时钟 |
| xlconstant_tvalid | `CONST_VAL=1` 1bit | 修 adau tvalid 单脉冲漏拍 |
| xlconstant_0 / 1 | 常量 | RESTN端口 / clk_wiz复位 |
| axis_data_fifo_0 | AXIS缓冲 | 缓冲 |

**时钟/复位**：全 PL **单时钟域 100MHz**（FCLK_CLK0），`FCLK_RESET0_N→proc_sys_reset→peripheral_aresetn` 送到所有模块（含 bpm `ap_rst_n`）。clk_wiz 的 25MHz 只给 codec MCLK，不进 PL 数据域。

**AXIS 数据流连接**（TCL 原文）：
```
adau.M_AXIS → axis_data_fifo.S_AXIS → axis_data_fifo.M_AXIS → segment.S_AXIS
segment.M_AXIS → bpm.audio_in → bpm.audio_out → axi_dma.S_AXIS_S2MM → axi_mem_intercon → PS.S_AXI_HP0
```

## 四、地址映射（各 IP 基址 + 关键寄存器）

| 地址 | 模块 | 说明 |
|------|------|------|
| 0x40000000 | bpm_detect_0 | HLS s_axilite |
| 0x41E00000 | axi_dma_0 | DMA 寄存器 |
| 0x43C00000 | segment_stream_0 | 计数门控 |
| 0x44A00000 | adau1761_0 | s_axilite（音频经 I2C 0x3B 配） |
| 0x00000000（0x20000000=512MB） | DDR | DMA 写目标（HP0） |

**bpm_detect_0 寄存器（基址 0x40000000，s_axilite 数组接口，新/旧口径一致）：**
| 偏移 | 字段 | 类型 | 含义 |
|------|------|------|------|
| 0x10 | regs[0]=total_samples | RW | 仅 C-sim 有界退出，硬件忽略 |
| **0x28** | regs[6]=**bpm_value** | RO float | 实时 BPM（`struct.unpack('<f',...)` 读） |
| **0x2C** | regs[7]=**debug_cnt** | RO | 检测到的峰/节拍累计次数 |
| **0x30** | regs[8]=**energy_ratio** | RO | 当前窗包络能量低32位（板上观测） |

> ⚠️ **重要兼容性修正（本次提前发现）**：HLS 若用 `struct *regs` 接口，寄存器会从 0x10 起顺序排，BPM 落在 **0x14**，与旧版/现有脚本读的 0x28 不一致。已改为 **`uint32_t regs[]` 数组接口**，使 BPM@0x28、debug@0x2C、ratio@0x30 与旧能量比 IP 完全一致，**现有 PYNQ 脚本零修改**。

## 五、DMA 运行方式（实测唯一可用模式）

axi_dma_0 仅 S2MM，数据从 bpm.audio_out 收流写 DDR。驱动要点（踩过多个坑总结）：

```
# 每帧必须: transfer(); start(); sleep
seg.mmio.write(0x00, 8192)          # segment 放行一帧
buf = allocate(shape=(N,), dtype=uint32)
dma.recvchannel.transfer(buf)
dma.recvchannel.start()
time.sleep(0.15~0.4)                 # 关键, 给 DMA 时间收满
# 此时 buffer 里是 N 个 32bit 词, 每词高24位为一条声道样本(交织)
```

**已证不可用模式**（不要再犯）：
- ❌ `dma.recvchannel.wait()` 无参 → 死等
- ❌ `while not dma.recvchannel.idle` → 挂死
- ❌ `start()` 一次 + 循环 `transfer()` → 第1帧报 "not idle"
- ✔ **只有** 每帧独立 `transfer(); start(); sleep` 可靠

## 六、Jupyter 里做了哪些配置（为合理发挥 XSA）

1. `Overlay(BIT)` 加载 bit+hwh，取 `ol.adau1761_0 / segment_stream_0 / bpm_detect_0 / axi_dma_0`
2. `smbus2`(I2C 0x3B) 全量初始化 ADAU1761，**必须含 MIC 增益**：
   `R4/R6=0x11`输入通道、`R5/R7=0x10`(**+20dB MIC boost**)、`R8/R9=0x60`中档音量、`R10=0x01`MIC偏置、`R19=0x33`
3. segment 写 `REG0=8192` 放行一帧
4. DMA 每帧 `transfer();start();sleep`（第四节）
5. MMIO 轮询读 bpm：`bpm.mmio.read(0x28)` 用 `struct.unpack` 解 float
6. 波形显示：原始 24bit 解码 `(a[::2]^0x800000)-0x800000`，G1 用 **autoscale**（不要固定 ylim）

## 七、遇到的困难 & 是否已解决

| 困难 | 根因 | 状态 |
|------|------|------|
| BPM 恒为 0 | 能量比值法 `window/avg>1.5` 在真音频稳态只有 0.05 | ✅ 弃用，改 Pan-Tompkins |

## 八、已验证链路下的 Jupyter 代码架构（推荐骨架）

```python
import time, struct
import numpy as np
from pynq import Overlay, allocate

ol = Overlay("design_1.bit")
seg, bpm, dma = ol.segment_stream_0, ol.bpm_detect_0, ol.axi_dma_0

# 1) 固定顺序初始化
import smbus2; bus = smbus2.SMBus(0); CAD = 0x3B
def wr16(r,v): bus.write_i2c_block_data(CAD,(r>>8)&0xFF,[r&0xFF,v])
for r,v in [(0x400A,0x11),(0x400B,0x10),(0x400C,0x11),(0x400D,0x10),
            (0x400E,0x60),(0x400F,0x60),(0x4010,0x01),(0x4026,0x33)]:
    wr16(r,v); time.sleep(0.005)         # 含MIC boost, 中档音量

N = 8192
buf = allocate(shape=(N,), dtype=np.uint32)
def get_frame():
    seg.mmio.write(0x00, N)              # 放行一帧
    dma.recvchannel.transfer(buf); dma.recvchannel.start()
    time.sleep(0.2)
    a = np.asarray(buf)
    return ((a[::2]^0x800000).astype(np.int32)-0x800000)  # 单声道 24bit

def get_bpm():
    v = bpm.mmio.read(0x28)              # float BPM
    return struct.unpack('<f', struct.pack('<I', v))[0]

try:
    for i in range(60):                  # 采60帧
        raw = get_frame()                # → G1 波形(autoscale)
        b   = get_bpm()                  # → G2 BPM曲线
        print(i, raw.max(), b)
finally:                                 # 中断必输出汇总
    print("done")
```

**避坑清单（都曾犯过）**：
- ✔ 每帧 `transfer();start();sleep`；禁 `wait()`/`while not idle`/`start`一次复用
- ✔ codec 配置**一次写全**（含 R5/R7 MIC boost）；音量 0x60 防削波
- ✔ bpm 0x28 要 `struct.unpack` 解 float；debug@0x2C、ratio@0x30
- ✔ 波形 x 轴 autoscale；原始解码 `(a[::2]^0x800000)-0x800000`
- ✔ 刺激用手机外放对准 MIC，别拍桌
- ✔ Jupyter 脚本用标准多行文本（避免单行 `SyntaxError`）
- ✔ 采集循环包 `try/finally`，中断后输出汇总
